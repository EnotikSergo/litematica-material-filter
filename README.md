# Litematica Material Filter

An add-on for **Litematica**.

Allows you to filter the material list by search query and display only the required blocks in the **Info HUD**, without manually clicking **Ignore** for every unnecessary material.

## Usage

1. Load a schematic in Litematica, open the **`Material List`**, and there will be a button to **`Open Filter`**.
2. The filter screen will open:
   - Enter a search query, for example `oak` — the list will instantly show only oak-related blocks.
   - You can just click and select the desired one.
   - Click **`▶ Apply to HUD`**.
3. Enable the **Info HUD** in Litematica — only the filtered blocks will be displayed on the screen.
4. To remove the filter, open the filter screen again and click **`✕ Clear Filter`**.
