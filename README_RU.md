# Litematica Material Filter

Аддон для **Litematica**

Позволяет фильтровать список материалов по запросу и выводить в **Панель информации** или в Голограмму схемы в мире
только нужные блоки - без ручного нажатия «Игнорировать» на каждый лишний материал.

## Использование

1. Загрузи схему в Litematica, дальше выбери **`Список материалов`**, и там будет кнопка **`Открыть Фильтр`** или просто кнопка **`N`** по умолчанию. Так же последняя активная схема буде загружена автоматически
2. Появится экран фильтра:
   - Введи запрос, например `дуб` — список сразу покажет только блоки в названии которых есть дуб, можно вводить так же на английском, весь список можно сразу приметить к фильтру нажав **`Применить к HUD`** или **`Применить к Голограмме`**.
   - Можно так же просто кликать и выбирать нужное (**`ЛКМ`** выбор фильтра для Списка материалов, **`ПКМ`** выбор фильтра для Голограммы блоков в мире).
   <img width="948" height="141" alt="image" src="https://github.com/user-attachments/assets/dfbe5331-1cfb-43fc-9b60-e1192b1ffb23" />

   - **`Зеленый`** — фильтр для HUD; **`Синий`** — фильтр для голограммы; **`Желтый`** — применены оба фильтра к данному блоку

   - **`Фильтр голограммы: ON/OFF`** включает и выключает использование фильтра для фильтрации блоков рендера схемы в мире
   - **`Режим Белый/Черный список`** может идти как по белому списку, так и по черному списку материалов или голограммы
   - **`Сущности`** включает и выключает отображение сущностей и анимацию жидкостей на схеме.
     На скриншоте включен белый список фильтра голограммы на редстоун блок
     <img width="820" height="427" alt="image" src="https://github.com/user-attachments/assets/0225f036-934a-441b-84cc-c9d4f368174c" />

4. **`Материал HUD`**, включает панельку со Списком материалов, а **`Исходный HUD`**, включает панельку со Списком материалов которые можно разложить на исходные материалы крафта.

4. При включенном **`исходном HUD, при нажатии [+]`** данный материал раскладывается на составляющие, можно как раскрыть полностью все материалы, так и свернуть их

5. Чтобы снять фильтр - нажми **`✕ Очистить фильтр`**.
