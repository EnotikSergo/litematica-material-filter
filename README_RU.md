# Litematica Material Filter

Аддон для **Litematica**

Позволяет фильтровать список материалов по запросу и выводить в **Панель информации**
только нужные блоки — без ручного нажатия «Игнорировать» на каждый лишний материал.

## Использование

1. Загрузи схему в Litematica, дальше выбери **`Список материалов`**, и там будет кнопка **`Открыть Фильтр`**.
2. Появится экран фильтра:
   - Введи запрос, например `дуб` — список сразу покажет только блоки из дуба.
   - Можно так же просто кликать и выбирать нужное.
   - Нажми **`▶ Применить к HUD`**.
3. Теперь включи **Панель информации** в Litematica — на экране будут только отфильтрованные блоки.
4. Чтобы снять фильтр — открой экран снова и нажми **`✕ Очистить фильтр`**.
