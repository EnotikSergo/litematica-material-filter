# Litematica Material Filter

Аддон для **Litematica**

Позволяет фильтровать список материалов по запросу и выводить в **Панель информации** или в Рендер схемы в мире
только нужные блоки - без ручного нажатия «Игнорировать» на каждый лишний материал.

## Использование

1. Загрузи схему в Litematica, дальше выбери **`Список материалов`**, и там будет кнопка **`Открыть Фильтр`** или просто кнопка **`N`** по умолчанию.
2. Появится экран фильтра:
   - Введи запрос, например `дуб` — список сразу покажет только блоки в названии которых есть дуб, можно вводить так же на английском, весь список можно сразу приметить к фильтру нажав **`Применить к HUD`** или **`Применить к Рендеру`**.
   - Можно так же просто кликать и выбирать нужное (**`ЛКМ`** выбор фильтра для Списка материалов, **`ПКМ`** выбор фильтра для Рендера блоков в мире на схеме).
   - **`Фильтр рендера`** включает и выключает использование фильтра для фильтрации блоков рендера схемы в мире
   - **`Режим рендера`** может идти как по белому списку, так и по черному списку
   - **`Сущности`** включает и выключает отображение сущностей и анимацию жидкостей на схеме.
     На скриншоте включен белый список фильтра на редстоун блок
     <img width="820" height="427" alt="image" src="https://github.com/user-attachments/assets/0225f036-934a-441b-84cc-c9d4f368174c" />

3. **`Материал HUD`**, включает панельку со Списком материалов, а **`Исходный HUD`**, включает панельку со Списком материалов которые можно разложить на исходные материалы крафта.

4. При включенном **`исходном HUD, при нажатии [+]`** данный материал раскладывается на составляющие, можно как раскрыть полностью все материалы, так и свернуть их
