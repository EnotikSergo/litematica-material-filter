# Litematica Material Filter

Аддон для **Litematica**

Позволяет фильтровать список материалов по запросу и выводить в **Панель информации**
только нужные блоки — без ручного нажатия «Игнорировать» на каждый лишний материал.

---

## Использование

1. Загрузи схему в Litematica и выбери Список материалов, выйди из меню.
2. Нажми клавишу **`.` (Точка)** (можно сменить в настройках управления).
3. Появится экран фильтра:
   - Введи запрос, например `дуб` — список сразу покажет только блоки из дуба.
   - Нажми **`▶ Apply to HUD`** (или Enter).
4. Теперь включи **Панель информации** в Litematica — на экране будут только отфильтрованные блоки.
5. Чтобы снять фильтр — открой экран снова и нажми **`✕ Очистить фильтр`**.
